# Raga Alchemy 🎵

A comprehensive AI-powered Indian Classical Music system that bridges traditional raga-based music with modern machine learning technologies.

## Features

### 🎭 Emotion to Raga Mapper
- Real-time emotion detection from facial expressions
- Intelligent raga recommendations based on mood
- Personalized music experience

### 🎹 MIDI Generation
- Authentic raga-based melody generation
- Support for 10+ classical ragas with proper grammar
- Multiple output formats (MIDI, text, audio)
- Indian classical expression (meend, gamak)

### 🎤 Raga & Swara Detection
- Real-time audio analysis for raga identification
- Swara detection with pitch accuracy measurement
- Performance evaluation and feedback
- Support for multiple scales and pitches

## Technology Stack

### Backend
- **Flask** - Python web framework
- **TensorFlow/Keras** - Deep learning
- **Librosa** - Audio analysis
- **PrettyMIDI** - MIDI generation
- **Scikit-learn** - Machine learning models

### Frontend
- **React** - User interface
- **Custom CSS** - Indian-style aesthetic
- **Web Audio API** - Real-time audio processing

### Machine Learning
- **CNN** - Emotion detection
- **MLP/Random Forest** - Raga classification
- **SVM** - Swara detection
- **Markov Chains** - Music generation
